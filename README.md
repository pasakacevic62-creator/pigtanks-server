# PIG TANKS — сервер (аккаунты, топ, промокоды, версии)

Запуск локально: `node server.js` (порт из PORT, по умолчанию 8080).

Настройки (переменные окружения, все необязательные):
- LATEST_BUILD  — номер сборки последней версии игры (0.75 = 5)
- DOWNLOAD_URL  — ссылка на скачивание новой версии (показывается в старой)
- PROMOS        — промокоды "КОД:активаций:награда", через запятую. По умолчанию KAKTUS:3:cactus
- DATA_FILE     — путь к файлу данных (для постоянного диска)

Проверка: открыть /health — должен ответить {"ok":true,...}
